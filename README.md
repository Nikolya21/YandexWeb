# CampusNode — Академическая база знаний МФТИ

Веб-приложение для структурированного хранения и обмена техов и учебных материалов по факультетам и курсам.


---

## 🛠 Технологический стек

* **Фронтенд:** React 19, TypeScript
* **Управление состоянием:** Redux Toolkit (`createSlice`, `createAsyncThunk`)
* **Маршрутизация:** React Router v7
* **Сборка и разработка:** Vite (конфигурация Multi-Page App)
* **Тестирование:** Vitest, React Testing Library, `jsdom`
* **Хранение данных (MVP):** `localStorage`

---

## ✨ Реализованный функционал (Frontend MVP)

1. **Две точки входа в проекте:**
   * `/index.html` — информационный лендинг проекта.
   * `/app.html` — интерактивное SPA-приложение.
2. **Авторизация и управление аккаунтами (`/login`, `/register`):**
   * Регистрация новых пользователей с клиентской валидацией полей (имя, корректность email, длина пароля).
   * Отображение списка ранее зарегистрированных аккаунтов из `localStorage` с быстрым выбором профиля и проверкой пароля.
3. **Иерархический каталог и создание тем (`/`):**
   * Навигация по 9 факультетам МФТИ (ВШПИ, ФПМИ, ФРКТ, ФЭФМ, ЛФИ, ВШБТ, ФАКТ, ПИШ ФАЛТ, КНТ) и 4 курсам обучения с хлебными крошками.
   * Создание папок учебных предметов авторизованными пользователями с защитой от дубликатов внутри курса.
4. **Внутренняя страница предмета и система фидбека (`/subject/:subjectId`):**
   * **Разграничение прав доступа:** добавлять и удалять файлы внутри папки может только её создатель (`authorEmail`).
   * **Карточки файлов и 3-колоночное меню:** в левом верхнем углу каждой карточки расположена кнопка меню, открывающая три действия — отправку **жалобы**, запись **опечатки** и постановку/снятие **звездочки (лайка)** через Redux Toolkit.
5. **Адаптивный интерфейс:**
   * Единая дизайн-система для ПК, планшетов и мобильных экранов.

## 🚀 Инструкция по запуску

### 1. Установка зависимостей
Убедитесь, что у вас установлен **Node.js** (версии 18 или выше). В корневой папке проекта выполните:
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте в браузере:
* **Лендинг:** `http://localhost:5173/`
* **Веб-приложение (MVP):** `http://localhost:5173/app.html`

### 3. Запуск тестов и проверка покрытия
В проекте написано 5 тестовых наборов (17 тестов), проверяющих Redux-редьюсеры, API-слой, валидацию форм, защиту от дубликатов и разграничение прав автора:
```bash
npm test
```
Для просмотра подробного отчета о покрытии кода (Coverage):
```bash
npx vitest run --coverage
```

### 4. Сборка production-версии
```bash
npm run build
```
Готовые статические файлы будут собраны в папку `dist/`.
